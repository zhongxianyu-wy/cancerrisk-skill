# 知识需求矩阵（Knowledge Need Matrix）

**任务**：P0-T2 — 唯一整合报告各板块 × 各功能模块的数据需求清单  
**范围**：需求侧分析；仅列出"需要什么数据"及来源类型。不评估现有数据是否满足（差集分析为 T3）。  
**生成日期**：2026-06-05  
**依据**：`2026-06-05-cancerrisk-v1.4-design.md` §4/§5，`engine_contract_baseline.md`，`temp/html-preview-2`（阴性），`temp/html-preview-7`（阳性）

---

## 来源类型约定

| 标签 | 含义 |
|------|------|
| `结构化引擎库` | 贝叶斯引擎直接读取的 JSON 文件（`evidence_store/`）中已有的字段 |
| `引擎产出` | `snapshot_risk.py` 脚本计算后写入快照 JSON 的结果字段；亦包含健康总结 API 的输出（内部分析）|
| `MD按需库` | 按需加载的 Markdown 知识文件（`database_new/…/md/`），供 LLM 参考解读 |

> **注**：健康总结 API 产出（非癌症异常指标）划为 `引擎产出`，属于独立分析管线产出，与贝叶斯癌症引擎并列；该划分为设计约定，标注备注以示区分。

## 15 癌种覆盖范围

以下所有"来源为 `结构化引擎库`"的数据项，均需覆盖以下 15 个癌种：

> 肺癌 / 肝癌 / 胃癌 / 食管癌 / 结直肠癌 / 乳腺癌 / 宫颈癌 / 前列腺癌 / 膀胱癌 / 卵巢癌 / 肾癌 / 头颈癌 / 胆道癌 / 甲状腺癌 / 胰腺癌

以下所有"来源为 `MD按需库`"的数据项，均需在各癌种对应的指南 MD 和专题 MD 中可检索到相关内容（按需命中，非全量预加载）。

## 板块 1：报头 + 高危标签摘要

**呈现内容**：受检人基础信息；核心风险暴露标签；阳性时叠加遗传/现症红色警示（如 BRCA1 + 吉早安阳性方向）。

| 数据项 | 来源类型 | 覆盖范围 | 备注 |
|--------|----------|----------|------|
| 受检人姓名、性别、年龄 | `引擎产出` | 个人档案 | 来自 OCR + 苏格拉底问卷收集的人口学字段 |
| 报告编号 / 生成时间 | `引擎产出` | — | orchestrator 运行时写入 |
| 核心风险暴露摘要（如"重度吸烟、一级亲属癌症史"） | `引擎产出` | — | 健康总结 API 输出 + 苏格拉底问卷汇总 |
| 遗传突变状态（BRCA1/BRCA2/Lynch 携带者标志） | `引擎产出` | 乳腺/卵巢/结直肠/胰腺/子宫内膜（BRCA/Lynch 相关癌种） | 来自苏格拉底问卷 CP2 收集；阳性触发红色警示分支 |
| 液体活检结果摘要（阳性/阴性 + TOP信号癌种） | `引擎产出` | 吉早安覆盖癌种（见板块4） | 来自 OCR 解析吉早安报告字段 |
| 遗传风险终生概率说明文案（如"乳腺癌终生风险60-80%"） | `MD按需库` | BRCA/Lynch 相关癌种 | 来自 `09-遗传性高危基因证据.md` |

## 板块 2：核心建议执行时间轴

**呈现内容**：三档看板——🔴 优先执行（1-2周内）/ 🟠 重要检查（1个月内）/ 🟢 持续管理（3-6个月）；LLM 按疾病严重程度将加项分档，力求三档均匀。

| 数据项 | 来源类型 | 覆盖范围 | 备注 |
|--------|----------|----------|------|
| 各加项推荐检查名称（填入时间轴条目） | `MD按需库` | 全部命中的癌种 + 非癌症异常 | 来自筛查指南 MD / 专题 MD；名称须与 1+X 表保持一致 |
| 时间轴分档依据：疾病严重度 / 紧迫性分级 | `MD按需库` | 癌症及非癌症异常 | 来自各癌种筛查指南 MD（高危人群触发条件、推荐时机描述）|
| 癌症触发行的后验概率（用于排序，如"肠癌 3.99%"） | `引擎产出` | 15 癌种（命中者） | 贝叶斯引擎产出；后验概率高 / 风险等级高者优先入 🔴 档 |
| 液体活检阳性 TOP 信号癌种（阳性分支额外触发） | `引擎产出` | 吉早安阳性时命中的癌种 | 与贝叶斯后验叠加后，推入 🔴 优先执行 |
| 非癌症异常指标推荐检查（如 HbA1c、颈动脉超声） | `引擎产出` | 非癌症异常（健康总结 API 输出） | 健康总结分析产出；剔除已在癌症行列出的加项 |
